Bundle for Claude

    
Collects, under 28 MB:
      
· the Unity and Syndicate skeletons (male and female)
      
· the Aveline skirt pack, plus the Aveline and Élise outfit skeletons
      
· three Unity sword clips
      
· your known Élise bone list
      
· the forge header diagnostics and this log
      
Then drag the zip into the cloud chat. It only reads the forges, never writes to them.

    
    

  






  

    
k25 · Aveline skirt colliders for Ishpreet

    
Puts the cloth settings and leg colliders of Evie's Aveline skirt (Hips, Spine, both thighs, both shins) into Ishpreet's installed cloth pack, in place of the open-coat ones that let the skirt wrap one leg. Nothing else changes: same files, same sizes, same IDs. It writes a .data pack plus a rollback copy to out/k25/. It does not install anything: install with acs_kit's forge.install while the game is closed.

    
    

  






  

    
Unity sword → Syndicate

    
Lists Arno's sword clips (Unity DataPC.forge) and the Syndicate clips they could replace (DataPC_extra.forge, pack NewDemo_DEV). The 2026-10-10 check found every bone the sword clips animate in Syndicate's base skeletons. Run Check bones on any clip to confirm it for that clip. Attacker and defender (_Atk/_Dfn) clips are linked: map both, or kills desync.

Fight data for Claude (true 4th style)

    
Exports both fight graphs (Syndicate and Unity NewDemo_DEV), the weapon type, inventory item, UI icon binding and gear-tab records from both games, and Syndicate's leftover Sword/Long/Heavy clips. Output: one or more claude_fight_…_partNofM.zip files (each under 28 MB). Send all parts. The first run indexes Syndicate's DataPC.forge and can take a few minutes.

    
    
    

  

  

    
Mapping

    
Select a Unity clip on the left (click its name), then a Syndicate slot on the right. Paired clips are added together automatically when both sides have a pair. Save plan writes out/sword/sword_plan.json and extracts the chosen Unity clips next to it, ready for AnvilToolkit's XML export/import step and for the cloud session.
